    Convert an Excel spreadsheet into a Word document

    Spreadsheets are good at holding structured records and bad at reading like a document. This tool takes one sheet and turns every row into its own section of a Word file: a heading you choose, then the columns you choose underneath it, in the order you put them. A 200-row directory becomes a 200-entry clean document without copying a single cell by hand.

    How it works

    1. Upload a .xlsx or .xlsm file and pick the sheet you want. Nothing to install — it runs in the browser on any operating system.
    2. Choose the heading column. Whatever sits in that column becomes the title of each section: a person's name, a product code, a site reference.
    3. Arrange the remaining columns into the order they should appear, and leave out any you don't need.
    4. Add an optional report title and download the .docx.

    What the Word file looks like

    Each row becomes a Heading 1 carrying the value from your heading column, followed by one paragraph per remaining column with the label in bold. It uses Word's real heading styles rather than hand-formatted text. Empty cells keep their label and leave the value blank, so the structure stays consistent from one entry to the next.

    Values come through as text. Formulas arrive as their calculated result, while cell colours, fonts and conditional formatting are not carried across — the point is a clean document you can style in Word, not a picture of your spreadsheet.

    What people use it for

    • Office Staff working with spreadsheets and need a cleaner word document
    • Product and catalogue sheets, written up one entry per product
    • Survey responses turned into a readable write-up, one respondent per section
    • Asset registers, site lists and risk registers — anything held one record per row
    • Interview or case notes kept in a tracker that need to read as a report

    Common questions

    Do I need an account?

    No. Three files a month on this tool without signing up. Subscribe for unlimited number of files.

    Which file types can I upload?

    .xlsx and .xlsm, up to 10 MB. The older .xls format isn't supported — open it in Excel and save it as .xlsx first.

    What happens to my file?

    It's processed for your session and deleted within the hour. It isn't kept, shared, or used for anything else.

    Can I control the fonts and colours?

    Not in this tool — the output deliberately uses Word's default styles, which makes it easy to restyle afterwards. Run the result through Format Report to add a cover page, a branded header and footer, and a consistent theme.

    Can I pick which columns appear?

    Yes. Only the columns you arrange are included, in the order you set. Anything you leave out is ignored.

    Is there a limit on rows?

    No fixed row limit — the 10 MB file size is the practical ceiling. Very large sheets simply take a few seconds longer to build.
